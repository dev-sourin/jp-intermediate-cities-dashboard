# 日本の中都市 135市 特徴ダッシュボード

政令指定都市・東京都特別区を除く人口15万人以上の市（総務省統計局の都市規模区分でいう「中都市」）135市を、人口・産業構成・地域特色から比較できるインタラクティブ・ダッシュボードです。

外部CDNに一切依存しない単一HTMLファイルで、オフラインでもそのまま動作します。

**公開URL:** https://jp-intermediate-cities-dashboard.vercel.app

## 機能

| タブ | 内容 |
| --- | --- |
| 概要 | 全国マップ（円の大きさ=人口、色=特色、沖縄はインセット表示）、人口TOP20、地方ブロック別・特色別の分布 |
| 産業分析 | 第1次・第2次産業比率のTOP15、2次×3次産業比率の散布図、地方ブロック×特色のクロス集計 |
| 都市比較 | 最大4市を選んでレーダーチャート・人口・各指標を並列比較 |
| 一覧 | 135市の全件表。検索・地方/特色/産業構成タイプでの絞り込み・全列ソートに対応 |

ライト/ダークの両テーマに対応し、閲覧環境の設定に追従します。

## 分類について

**特色**と**産業構成タイプ**は別の指標です。

- **特色**（7分類）— 地理・歴史・知名度などを踏まえた**定性的**な分類です。公式統計ではありません。
- **産業構成タイプ**（4分類）— 令和2年国勢調査の就業者3部門比率から、以下のしきい値で機械的に判定した**定量的**な分類です。
  - 第1次産業比率高: 1次 ≥ 5%
  - 第2次産業比率高（工業型）: 2次 ≥ 30%
  - 第3次産業比率高（サービス型）: 3次 ≥ 80%
  - 標準型: 上記以外

両者が食い違う12市には一覧タブで ⚠ を表示し、「乖離ありのみ」で絞り込めます。定性分類を鵜呑みにせず、統計値と突き合わせて読めるようにするための表示です。

## データ出典

| データ | 出典 | 基準日 |
| --- | --- | --- |
| 人口 | [uub.jp 全国の市 人口ランキング](https://uub.jp/rnk/c_j.html)（令和7年国勢調査人口速報値） | 2025年10月1日 |
| 産業3部門別就業者数 | 総務省統計局「統計でみる市区町村のすがた」（令和2年国勢調査） | 2020年10月1日 |
| 行政区域界 | [dataofjapan/land](https://github.com/dataofjapan/land)（GeoJSON、簡略化して使用） | — |

`data/` に元データを置いています。`city_data_v2.json` がダッシュボードに埋め込まれている最終形です。

## ローカルでの表示

`index.html` をブラウザで開くだけです。ビルド手順もサーバーも不要です。

```
open index.html
```
